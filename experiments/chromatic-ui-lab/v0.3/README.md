# Chromatic UI Lab — v0.3

Laboratório experimental de composição de paletas cromáticas para aplicações web. **Não altera os tokens canônicos ou componentes existentes do Design System.**

## Execução

Abra [index.html](./index.html) diretamente no navegador. HTML/CSS/JavaScript autocontidos, sem build nem servidor.

## Recursos

- Círculo cromático interativo com pontos arrastáveis por matiz (HSL).
- Harmonias análoga, complementar, triádica, tetrádica, monocromática e complementar dividida.
- Dependência rotacional individual: checkbox para vincular ou liberar cada vetor.
- Edição de Background, Surface, Surface Elevated, acentos e cores semânticas.
- Prévia instantânea de navegação, cards, gráficos, tabelas, formulários e status.
- Exportação do contrato cromático ao final da página, incluindo valores HEX e vínculos.

## Escopo

O experimento é uma ferramenta de exploração. Uma paleta escolhida deve ser revisada quanto a contraste e acessibilidade antes de promoção aos tokens do Design System. HSL é usado para manipulação da matiz; futura evolução pode explorar OKLCH.
